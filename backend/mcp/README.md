# Konfigurasi MCP Bob

`bob_mcp_config.json` adalah contoh dan berisi placeholder, bukan kredensial. Untuk konfigurasi Bob yang aktif, gunakan berkas lokal privat di luar Git, lalu isi URL dan API key Langflow secara pribadi. Jangan memasukkan key ke berkas yang dilacak atau membagikannya lewat screenshot.

Key yang pernah tercantum dalam riwayat Git harus dianggap terpapar sampai dicabut di Langflow. Sebelum pencabutan, buat key pengganti, perbarui `LANGFLOW_API_KEY` di `.env` privat dan konfigurasi MCP Bob yang aktif, kemudian uji keduanya. Pastikan key lama yang akan dicabut teridentifikasi dengan benar. Bila masih ada klien lain yang menggunakannya, perbarui juga konfigurasinya.
